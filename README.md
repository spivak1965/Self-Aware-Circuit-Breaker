Self-Aware Circuit Breaker

## Project Overview
The Self-Aware Circuit Breaker is an intelligent protection system that predicts electrical spikes
before they occur and disconnects the load proactively.  
Unlike traditional circuit breakers that react after a fault, this system anticipates unsafe
conditions and isolates the load in advance.

---

## Objective
- Monitor current and voltage in real time
- Predict upcoming electrical spikes
- Disconnect the load before damage occurs
- Demonstrate identical logic for software simulation and hardware implementation

---

## System Components

### Inputs
- ACS712 30A current sensor
- Voltage measurement module

### Controller
- Arduino microcontroller

### Output
- Solid State Relay (ZGT-25DA)

### Load
- Lamp (resistive load)

### Software
- Python for simulation, prediction logic, and visualization
- Arduino firmware for real-time control

---

## High-Level Operation
- Current and voltage are continuously monitored
- A prediction algorithm checks for upcoming spike behavior
- If a spike is predicted:
  - Arduino turns OFF the solid-state relay
  - Load is disconnected before unsafe conditions occur
- When conditions return to normal:
  - Load operation resumes

---

## Prediction Logic
- Electrical spikes are modeled as gradual increases in current and voltage
- A prediction window is used to anticipate spikes before they peak
- The system trips preemptively instead of reacting after threshold violation

Note:
The spike behavior in this project is simulated in software using Python.
The control logic remains exactly the same if the spike is generated by real hardware conditions.

---

## Software Simulation (Python)
- Simulates real-time current and voltage behavior
- Implements spike prediction logic
- Sends ON and OFF commands to Arduino using serial communication
- Visualizes:
  - Current
  - Voltage
  - Load ON/OFF state
  - Shutdown intervals during predicted spikes

---

## Embedded Control (Arduino)
- Receives serial commands from Python
- Controls the solid-state relay output pin
- Acts as the execution layer of the protection system
- Designed to resemble deterministic control logic used in PLC systems
